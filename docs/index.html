GMN AI is the control panel for running GGUF models on your own machine: pick a model, one click, and the server is ready for VS Code, Roo Code, Continue, Cline or OpenCode. No accounts, no internet required. Interface available in English, Español and 中文.

What's inside

Everything runs locally — nothing leaves your PC.
Model loading

Visual GGUF picker

Add multiple model folders and pick which one to load — no copying or moving files needed.

VRAM

TurboQuant

Quantizes the KV cache (q8_0, q4_0…) to fit more context in less VRAM, with Flash Attention enabled automatically.

Multi-model

Router mode

Serve several models at once from a folder, auto-loaded on demand per request — hot-swap without restarting.

Large models

MoE expert offload

Send MoE experts to CPU so you can run models that would not fit in your VRAM alone (Nemotron, Qwen 35B-A3B…).

Speed

Speculative decoding

N-gram, MTP or draft model: the engine predicts several tokens at once and confirms them for faster responses.

Monitoring

Live monitor

GPU usage, VRAM, temperature, RAM and CPU while the model is running — all inside the app.

Language

🇬🇧 EN · 🇪🇸 ES · 🇨🇳 ZH

Switch interface language in Appearance → Language. Restart the app to apply. English is the default.

Built-in chat

Chat / Playground

Markdown rendering + built-in web search (DuckDuckGo, no API key). Catalog of 28 cloud providers pre-configured (Groq, Gemini, OpenAI, Claude, Mistral, DeepSeek and more — 17 free, 11 paid). Just pick one and paste your API key.

Downloads

Hugging Face downloader

Search models by name, pick a .gguf file, download directly — always with a confirmation step before it starts.

Works with the tools you already use

OpenAI-compatible API — any client that speaks it just works.
